# English Master – Full Course v5.0

A static English-learning app for GitHub Pages. Upload all five files in the repository root.

## Exactly 2,000 original bilingual dictation prompts
- Grammar: 12 English tenses × 20 questions = 240
- Daily conversation: 30 topics × 20 questions = 600
- Workplace English: 29 topics × 40 questions = 1,160
- Total: 2,000 English/Vietnamese sentence pairs

## CEFR-inspired progression
- A1: familiar expressions, personal details, routines and simple requests
- A2: everyday exchanges, work messages, travel, meetings and service interactions
- B1: clearer explanations, opinions, project updates, technical troubleshooting and professional discussions

Level labels are an instructional mapping for this app, not an official CEFR certification or an official course from the referenced institutions.

## Features
- Vietnamese meaning appears before listening
- Browser English speech synthesis, voice selection and playback speed
- Dictation input, word-level comparison and approximate accuracy score
- Grammar / usage notes, hints, retry and progress tracking
- Course search and A1/A2/B1 filters
- 12 tenses, 30 everyday conversation topics, 29 workplace English topics
- Progress saved in browser LocalStorage
- Responsive desktop and mobile layout

## Content development references
The app uses original example sentences and translations. Its topic selection, CEFR progression and skill mix were informed by public learning frameworks and activity categories from:
- British Council LearnEnglish: CEFR-level listening, grammar and vocabulary resources. https://learnenglish.britishcouncil.org/
- VOA Learning English: Let's Learn English Level 1 course structure and practical speaking/vocabulary/writing lessons. https://learningenglish.voanews.com/p/5644.html
- Cambridge English: learner activities organised by skill and level (Basic A1-A2 and Independent B1-B2). https://www.cambridgeenglish.org/learning-english/activities-for-learners/
No third-party lesson text or audio is copied into this app. Audio is generated by the browser/operating system's available speech voices.

## Publish / update GitHub Pages
1. Extract the ZIP.
2. Upload and overwrite `index.html`, `style.css`, `app.js`, and `README.md`; also upload the new `course-data.js`.
3. Commit to the `main` branch.
4. Keep GitHub Pages set to `main` and `/(root)`.
5. Open the Pages URL and press Ctrl+F5.

## Storage and audio notes
Progress is local to the current browser profile and does not sync between devices. Browser voice availability and sound quality depend on the device and installed English voices. This package does not include professionally recorded MP3 audio.


## Version 6 – Smart Dictionary & refreshed design

- New balanced color palette: deep teal, sea-glass green, soft ivory and warm apricot accents (not an all-purple theme).
- Click any word in the checked answer or word-by-word result to open Smart Dictionary.
- Dictionary shows Vietnamese meaning (built-in entries first), part of speech, IPA, English definition, example and example translation where available.
- Online lookup fallback: Free Dictionary API for English definitions/phonetics and MyMemory for Vietnamese translation. Internet access is needed for words not included in the built-in dictionary.
- Play a word's pronunciation; save it to My Vocabulary; search, remove and export saved words as CSV.
- Saved vocabulary is stored in browser LocalStorage.

To update GitHub Pages, upload and overwrite all five files in the repository root: `index.html`, `style.css`, `app.js`, `course-data.js`, and `README.md`.
